# 별과 우주 탐구 — 중학교 3학년 과학

중학교 3학년 과학 **Ⅶ. 별과 우주** 단원의 차시별 활동 콘텐츠입니다.

🔗 **수업 사이트 바로가기: https://mschoi1203.github.io/star-parallax/**

## 차시 구성

| 차시 | 주제 | 주요 활동 | 파일 |
|---|---|---|---|
| 1 | 연주 시차로 별까지의 거리 구하기 | 지구 공전 시뮬레이션, 거리 계산 연습 | [1-parallax.html](https://mschoi1203.github.io/star-parallax/1-parallax.html) |
| 2 | 별의 밝기와 등급 | 빛의 퍼짐 시뮬레이션, 겉보기·절대 등급 비교 | [2-brightness.html](https://mschoi1203.github.io/star-parallax/2-brightness.html) |
| 3 | 별의 색과 표면 온도 | 온도에 따른 별의 색 변화, 분광형 | [3-color.html](https://mschoi1203.github.io/star-parallax/3-color.html) |
| 4 | 우리은하와 성단·성운 | 우리은하 위·옆 모습, 성단·성운 분류 | [4-galaxy.html](https://mschoi1203.github.io/star-parallax/4-galaxy.html) |
| 5 | 외부 은하와 우주 팽창 | 은하 모양 분류, 풍선 우주 팽창 시뮬레이션 | [5-expansion.html](https://mschoi1203.github.io/star-parallax/5-expansion.html) |
| 6 | 우주 탐사와 우리 생활 | 탐사의 역사, 생활 속 우주 기술 | [6-exploration.html](https://mschoi1203.github.io/star-parallax/6-exploration.html) |

## 각 차시의 흐름

학습 목표 → 개념 → 시뮬레이션 → 분류 활동 → 확인 문제 → 정리
